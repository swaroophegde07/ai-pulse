# AI Pulse

> A minimalist AI intelligence dashboard — aggregated news, research, and industry developments from reliable public sources. Summaries generated by Gemini. Updated twice daily.

---

## Architecture

```
┌─────────────────────────────────────────────────────┐
│                  GitHub Actions                     │
│   schedule (2×/day) or workflow_dispatch            │
│                                                     │
│  ┌──────────────┐    ┌──────────────┐               │
│  │ Python       │    │ Astro Build  │               │
│  │ Ingestion    │───▶│ (static SSG) │───▶ GitHub    │
│  │ Pipeline     │    │              │     Pages     │
│  └──────────────┘    └──────────────┘               │
└─────────────────────────────────────────────────────┘

Data flow:
  RSS feeds → feedparser → Gemini (summarize) → feed.json → Astro build → dist/
```

| Layer | Technology |
|---|---|
| Frontend | Astro 4, TypeScript, Tailwind CSS 3 (static SSG) |
| Data ingestion | Python 3.10+, feedparser, google-genai SDK |
| Storage | `src/data/feed.json` committed to Git |
| Search/filter | Client-side vanilla JS (no external service) |
| Automation | GitHub Actions (scheduled + manual) |
| Hosting | GitHub Pages (adaptable to any static host) |

```bash
pip install -r requirements-dev.txt
```

### 4. Install Node.js dependencies

```bash
npm install
```

---

## Running the Python Pipeline

```bash
# From the repository root:
python -m pipeline.run
```

This will:
1. Fetch RSS feeds from all configured sources.
2. Summarize new articles with Gemini.
3. Merge with any existing records in `src/data/feed.json`.
4. Write the updated file atomically.

Logs are printed to stdout. Articles already in the feed are skipped (no duplicate API calls).

## Adding RSS Sources

Open [`pipeline/sources.py`](pipeline/sources.py) and add a new entry to the `SOURCES` list:

```python
{
    "name": "Source display name",
    "url": "https://example.com/feed.xml",   # verified RSS/Atom URL
    "publisher": "Company or Organisation",
    "category": "News",                       # default category
},
```

**Allowed categories:** `News`, `Research`, `Benchmark`, `Product Release`, `Opinion`

The pipeline handles feed failures gracefully — a broken URL logs a warning and continues with the remaining sources.

## Configuring GitHub Actions

### Repository secrets

Go to **Settings → Secrets and variables → Actions** and add:

| Secret | Value |
|---|---|
| `GEMINI_API_KEY` | Your Google AI Studio API key |

### GitHub Pages deployment

1. Go to **Settings → Pages**.
2. Under **Source**, select **GitHub Actions**.
3. In [`astro.config.mjs`](astro.config.mjs), set your `site` URL:
   ```js
   site: "https://swaroophegde07.github.io",
   base: "/ai-pulse",
   ```
4. Push to `main`. The workflow runs automatically on schedule or via **Actions → Update and Deploy → Run workflow**.

### Workflow overview

The single workflow (`update-and-deploy.yml`) does:

1. **Ingest job** — Python tests → pipeline run → commit `feed.json` with `[skip ci]`
2. **Build and deploy job** — `npm ci` → `astro check` → `astro build` → deploy to Pages

The `[skip ci]` tag on the feed commit prevents the workflow from triggering itself recursively.

## Gemini API Usage and Costs

- The pipeline calls Gemini **once per new article** per run.
- Existing articles are not re-summarized.
- Default model: **`gemini-3.5-flash-lite`** — fast and cost-efficient.
- With 50 new articles/day and `gemini-3.5-flash-lite`, costs are typically a few cents per month on paid plans.
- The free tier (AI Studio) provides generous quotas for development.
- Check current pricing at [ai.google.dev/pricing](https://ai.google.dev/pricing).

> **Important:** AI-generated summaries may contain errors or omissions. Always verify information against the original source.

## Deploying to Other Static Hosts

The Astro build output (`dist/`) is a standard static site and can be deployed to:

- **Vercel** — `npm run build` → set output directory to `dist`
- **Netlify** — connect repo, build command `npm run build`, publish directory `dist`
- **Cloudflare Pages** — same as Netlify
- **AWS S3 + CloudFront** — upload `dist/` contents to an S3 bucket

Remove or comment out the GitHub Pages sections in the workflow, and add the appropriate deployment step for your host.

## Known Limitations

- **Static data** — the site is rebuilt twice daily. Very recent articles (< ~30 min old) may not appear immediately.
- **No full-text extraction** — the pipeline uses the summary or content fields provided by each RSS feed. Articles behind paywalls are excluded.
- **AI summaries** — Gemini summaries are approximate. They may miss nuance or occasionally misclassify articles. The pipeline validates the response before saving, and applies a documented fallback if validation fails.
- **Feed availability** — external RSS feeds can go offline or change their URL. Check `pipeline/sources.py` if a source stops appearing.
- **Rate limits** — if you add many sources, you may hit Gemini API rate limits. The pipeline includes retry logic and inter-request delays.
